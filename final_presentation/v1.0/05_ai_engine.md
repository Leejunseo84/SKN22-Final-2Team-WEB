# 05. AI 엔진: 지능형 대화 및 추천 로직

## 5.1 LangGraph 기반 대화 워크플로우
* **상태 관리**: 복잡한 대화 흐름을 노드(Node)와 에지(Edge)로 정의하여 사이클 제어
* **의도 분류(Intent Classifier)**: 질문의 목적(정보 검색, 상품 추천, 단순 인사 등)을 사전에 파악하여 최적의 경로 설정

## 5.2 RAG 및 하이브리드 검색
* **RAG (Retrieval-Augmented Generation)**: PostgreSQL에 저장된 고품질 지식 데이터를 참조하여 답변의 신뢰도 확보 (환각 현상 방지)
* **Hybrid Search Strategy**: 
    * 키워드 기반 검색(BM25)으로 정확한 상품명 매칭
    * 시맨틱 검색(Embedding)으로 사용자 의도 중심의 상품 추천

## 5.3 컨텍스트 기반 추천 엔진
* 유저의 반려동물 프로필(나이, 사료 알러지, 품종 특성)을 프롬프트와 검색 쿼리에 동적으로 주입하여 맞춤형 결과 생성
